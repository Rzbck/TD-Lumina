# Scene review history

Store standalone Scene Lab reviews here.

Reviews are append-only. Do not overwrite an old critique after a scene improves.

Recommended naming:

`YYYY-MM-DD_scene-XX_v0-2_context.json`

Examples:

- `2026-10-01_scene-04_v0-2_rhythmic.json`
- `2026-10-01_scene-11_v0-1_energetic.json`

Each file should conform to `../review-schema.json`.

A scene may have many reviews for different versions and music contexts. The registry status should change to `VALIDATED` only after the user explicitly accepts that scene.
